# 🐰 中班学习乐园 · 幼儿园中班家庭作业互动课堂

专为幼儿园中班（4–5 岁）小朋友设计的家庭学习网站：图文题目、互动作答、答案讲解、语音朗读、家长教学规划，一应俱全。**完全离线可用**，双击就能打开，无需安装任何东西。

## 🚀 怎么打开

**方法一（最简单）：** 双击 `index.html`，浏览器就会打开。

**方法二（局域网访问）：** 在文件夹里运行
```
python -m http.server 8000
```
然后用手机/平板浏览器访问 `http://电脑IP:8000`，孩子可以用平板做题。

**方法三（分享给爷爷奶奶家）：** 把整个文件夹拷到 U 盘就行，100% 离线可用。

> 推荐用 **Edge 或 Chrome** 打开，语音朗读效果最好。

## 🔉 语音功能（自动读题 + 答案语音讲解）

- 每道题出现时会**自动朗读题目**（可在 ⚙️ 设置里开关、调语速）。
- 答对/看答案后，会显示**通俗讲解**，并自动用语音念出来，点「🔊 听小老师讲一讲」可以重复听。
- 语音来自电脑/平板**自带的中文语音，无需联网**。
- 想换更好听的童声：Edge 浏览器 → 右上角 ⋯ → 设置 → 语音 → 可选「Microsoft Xiaoxiao（晓晓）」等自然语音，Win10/11 自带。

## ⭐ 星星激励 + 进度记录

- 自己答对：⭐×2；看答案后学会：⭐×1。
- 进度自动保存在浏览器里，家长专区能看到每个模块完成情况，可一键清空重来。

## 🖨️ 打印作业纸（布置作业神器）

- 任意练习组右上角「🖨️ 作业纸」→ 生成 A4 试卷：姓名/日期/题目配图/答题空行，**底部附家长答案区和讲解**。
- 家长专区可打印完整教学规划表（五大领域目标、周计划、分科进度）。

## 🔧 想自己加题目？

打开 `data_*.js`，按格式添加即可：
```js
{pic:'🍎', q:'苹果是什么颜色？', h:'想一想', opts:['红色','蓝色'], a:0,
 w:'苹果是红色的。'}
```
`a` 是正确答案的下标（从 0 开始），`w` 会同时显示和语音朗读。
