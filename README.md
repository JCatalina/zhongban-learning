# 🐰 中班学习乐园 · 幼儿园中班家庭作业互动课堂

专为幼儿园中班（4–5 岁）小朋友设计的家庭学习网站：图文题目、互动作答、答案讲解、语音朗读、家长教学规划，一应俱全。**完全离线可用**，双击就能打开，无需安装任何东西。

## 🚀 怎么打开

**方法一（最简单）：** 双击 `index.html`，浏览器就会打开。

**方法二（局域网访问）：** 在文件夹里运行
```
python -m http.server 8000
```
然后用手机/平板浏览器访问 `http://电脑IP:8000`，孩子可以用平板做题。

**方法三（分享给爷爷奶奶家）：** 把整个文件夹拷到 U 盘就行，100% 离线可用。

> 推荐用 **Edge 或 Chrome** 打开，语音朗读效果最好。

## 🎬 动画讲解（用 Remotion 制作的数学动画）

数学题（🔢数学园地、➕加减法乐园）的答案讲解区多了「🎬 动画讲解」按钮：

- 点击弹出**宽屏弹窗**，用 Remotion 播放器播放专为**当前这道题**定制的动画——题目是"5 块饼干吃掉 2 块"，动画里就真的画 5 块饼干、一口一口吃掉 2 块，再数一数剩下的。
- 共 9 类动画，覆盖全部数学题：**加法合起来、减法变少了（吃/飞走/游走/送人 4 种消失方式）、数的分成、数一数、比大小（大嘴巴鳄鱼 > < ＝）、排第几个、相邻数、单双数**。
- 可暂停、拖动进度条、反复重播；看完关闭弹窗继续做题。
- 动画在浏览器里实时渲染，**无需联网**，完全离线可用。

> 重新构建动画：`cd anim-src && npm install && npm run build`（输出到 `anim/anim-player.js`）。重新打包后请把 `index.html` 中 `anim-player.js?v=N` 的版本号 +1，避免浏览器继续用缓存里的旧动画。

## 🔉 语音功能（全站内置离线高保真童声音频）

- **547 个高保真 MP3 原声文件**：预生成微软晓晓自然童声（`zh-CN-XiaoxiaoNeural`），100% 离线同源播放，彻底告别微信浏览器“浏览器不支持”或静音问题。
- **自动读题与答案讲解**：每道题出现时自动朗读题目与选项；答对或查看答案后，自动朗读通俗易懂的儿童讲解。
- **下一题静默预加载**：答题过程中自动在后台预取下一题音频，点击下一题瞬间即可无缝发声。
- **朗读呼吸动效**：正在发音时朗读按钮伴随动态呼吸跳动光晕反馈。

## 🔧 想自己加题目？

打开 `data_*.js`，按格式添加即可：
```js
{pic:'🍎', q:'苹果是什么颜色？', h:'想一想', opts:['红色','蓝色'], a:0,
 w:'苹果是红色的。'}
```
`a` 是正确答案的下标（从 0 开始），`w` 会同时显示和语音朗读。
